# 公开数据演示：MBPP 过一遍 pipeline

跑于 2026-10-16（minimal 规则）。所有数字都来自这次真实运行。复现方法见下一节。

## 怎么复现

```bash
cd /path/to/Qwen3.8-27B-PT
python -m qwenpt.data download --sources configs/data/sources/github.yaml --out data/pipeline/
python -m qwenpt.data run --data data/pipeline/ --config configs/data/github_demo.yaml --out runs/demo
python -m qwenpt.data export --run runs/demo --out export/demo --config configs/data/github_demo.yaml
```

现在的下载配置还多了 GSM8K（训练集作候选、测试集作评测集）。上面的数字只针对 MBPP 部分。GSM8K 训练集里有 6 道题和测试集高度相似，被去污染删掉（13-gram 命中 5 道，嵌入命中 1 道）。

## 数据

| 角色 | 数据集 | 条数 | 许可证 |
| --- | --- | --- | --- |
| 训练候选 | MBPP 全部（含参考代码和 assert 测试） | 974 | CC-BY-4.0 |
| 评测集 | HumanEval | 164 | MIT |

训练候选里本来就包含 MBPP 测试集的原题。所以这 257 道题的原版应该被去污染全部找出来，可以用来量漏检。

## 去污染查得准不准

**漏检：257 道测试题里，有 80 道（31%）的原版没被找出来。** 漏掉的都是被作者改写过的题面，例如：

- 训练：「Write a function to find the perimeter of a square.」
- 评测：「Write a function that returns the perimeter of a square given its side length as input.」

**误检：214 条命中里，43 条匹配到的是另一道题，而且抽看的 12 条全是不同的题。** 例如：

- 「set all **odd** bits」与「set all **even** bits」
- 「**maximum** product from the pairs of tuples」与「**minimum** product ...」
- 「lateral surface area of a **cube**」与「... of a **cylinder**」

其中 32 条来自嵌入相似度，11 条来自 13-gram。13-gram 的误检是被「Write a python function to check whether the given number can be represented ...」这类模板句撞上的。

## 能从这次运行得出什么

- **去污染能找出大部分泄漏，但不是全部**（本项目实测）。故意混进训练候选的 257 道测试题原版，找出了 177 道（69%）。这里的泄漏是刻意构造的，不代表公开数据的真实泄漏率；真实情况可参考 RLVR 追溯论文发现的 36,148 条泄漏【论文】。
- **本地哈希嵌入不够用**【推论】。31% 的改写题漏检，和它能抓的改写程度一致。这里下载真实嵌入模型（bge-small）被网络拦下，没能对比。正式跑时应换成真实嵌入模型，再用这 257 对题量一次漏检率。
- **误检的代价小，漏检的代价大**【推论】。误检只是多删了约 4% 的训练题，漏检则会让评测分数虚高。所以阈值宁可松一点。
- **执行一致性在 MBPP 上没剔除任何题**。函数题的参考答案通常是好的；这一步主要是为 SWE 和终端环境准备的。
